## 🌟 Overview
EmpathibotAI is an **emotionally intelligent AI chatbot** designed to provide human-like, empathetic interactions. Powered by **advanced NLP, deep learning, and sentiment analysis**, it recognizes user emotions and responds with appropriate tone, language, and support.

🔗 **Live Demo:** [EmpathibotAI](https://empathibot.netlify.app/)

---

## 🚀 Features
- 🤖 **Emotion-Adaptive Responses** – AI detects user emotions and tailors responses accordingly.
- 🎨 **Modern UI/UX Design** – Glassmorphism and neumorphism elements with dynamic theme changes.
- 🗣 **Multi-Modal Communication** – Text, voice input, and emoji-based interactions.
- 🎭 **AI Avatar & Animated Expressions** – Enhances engagement with a reactive chatbot face.
- 🔄 **Contextual Memory** – Remembers conversation flow for personalized responses.
- 🌍 **Multi-Language Support** – Supports multiple languages for inclusivity.
- 🏆 **Seamless Cross-Platform Experience** – Fully responsive for web and mobile.

---

## ⚙️ Tech Stack
- **Frontend:** React.js, TailwindCSS, Bolt AI
- **Backend:** Node.js, Express, Bolt AI APIs
- **AI & NLP:** OpenAI GPT, Hugging Face Transformers, Sentiment Analysis, Bolt AI
- **Database:** Firebase / MongoDB
- **Deployment:** Netlify, Vercel

## 📦 Installation & Setup

### **Clone the Repository**
```bash
git clone https://github.com/yourusername/EmpathibotAI.git
cd EmpathibotAI
```

### **Install Dependencies**
```bash
npm install
```

### **Run the Development Server**
```bash
npm start
```

### **Build for Production**
```bash
npm run build
```

## 💡 How It Works
1. **User inputs a message** (text or voice).
2. **Sentiment & intent analysis** detects emotions.
3. **AI model generates an empathetic response** based on emotion and context.
4. **Chatbot displays an animated expression** while responding.
5. **User gets a meaningful, emotionally aware response.**
